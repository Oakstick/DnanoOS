# Adventures of the Ancient Blades (Rust + wgpu)

The game rebuilt in Rust from the TypeScript/Three.js version one folder up, feature for feature. It uses one codebase for two targets:

| Target | Graphics | How to build | Output |
|---|---|---|---|
| Windows executable (Steam) | wgpu over Direct3D 12, Vulkan as the fallback | `powershell -File build-windows.ps1` | `dist/windows/Adventures of the Ancient Blades.exe` |
| Web | WebAssembly over WebGPU, WebGL2 as the fallback | `powershell -File build-web.ps1` | `dist/web/` |

wgpu is Rust's implementation of the WebGPU API. The browser build uses the browser's own WebGPU, and the desktop build maps the same calls onto the native APIs. The shaders are WGSL either way.

## Requirements

- Rust stable (`rustup`), plus `rustup target add wasm32-unknown-unknown` for the web build
- `cargo install wasm-bindgen-cli --version 0.2.128` (it must match the `wasm-bindgen` version in `Cargo.lock`)
- On Windows, the Visual Studio C++ build tools (the Windows SDK's `rc.exe` embeds the icon)

## Running

```
cargo run -- --windowed          # debug build in a window
cargo run --release              # borderless fullscreen (F11 or Alt+Enter toggles)
cargo test                       # rules, level generation, movement, audio, input
```

Serve `web/` over http (for example `python -m http.server 5174 --directory web`) after `build-web.ps1`. Browsers will not load wasm from `file://`.

## Code layout and checks

The layers are described at the top of `src/lib.rs`: `logic` holds the rules with no rendering, audio or input in it; `game` ties the layers together (and still calls the view directly, the one coupling left to untangle), one module per part of the rules (the list is at the top of `src/game.rs`); `render/view` turns the state into draws, one module per concern (frame, models, camera, animation, effects, emit, and one per level look).

Before committing, run every check at once. It fails on a formatting difference, on any clippy warning (desktop, tests and web), or on a failing test:

```
powershell -File check.ps1
```

For a change that should not alter what the game does, such as a refactor, compare the capture suite before and after. It renders 26 seeded captures covering every stage and the main systems, and a render matches when the frame logs are identical and the pictures differ only by GPU noise:

```
python tools/capture_suite.py render before
python tools/capture_suite.py render after
python tools/capture_suite.py compare before after
```

Formatting follows `rustfmt.toml` (140 columns); lint settings are in `Cargo.toml` (`[lints]`) and `clippy.toml`.

## The Sparring Ring: combat by frame data

`COMBAT.md` is the combat specification and its roadmap: frame data for every move (startup, active, recovery), the formulas (power, damage with state multipliers and proration, poise and its breaks, hitstun decay), the fighter state machine with its input buffer and cancel rules, the threat manager (attack tokens, cadence, rings and sectors), and three archetypes built on foes already in the game. Phase 1 runs in the gym's **Sparring Ring**, west of the arrival platform (capture command `ring:N` for bout N):

- **The hero** fights with three verbs. **Attack** is a string of three (L1 6/4/14 frames, L2 5/4/16, L3 9/5/22); a press anywhere in a swing comes out as the next hit on its cancel frame. **Guard** (hold LB or Shift): a parry in its frames 2-9, a block for stamina after that, a broken guard when the stamina runs out. **Evade** (the leap) cancels any startup and leaves him untouchable in the air. Swings plant him and turn onto the nearest foe (a soft lock). Nothing in the ring touches his real shield, lives or gold.
- **His own gear, as numbers** (COMBAT.md §8): the blade he wields sets the string's power, poise, tempo (frames and stamina), reach, arc and finisher (a whirl sweeps all round; an axe, a spear or a bow throws it), and gifts like armour-piercing or critical blows. His shield sets the parry window (8 to 11 frames), what a block costs, and what a parry does back. His path adds what fits: rage, crits, a lighter landing, a backstab, terror, a second wind. Gifts that act outside the frame data (tricks, bleeds, burns, spirits) are cut in the ring, and those blades bite harder instead. A fresh Ragnar is exactly the table above. F8 shows the kit's numbers.
- **The Brute** (the blemmyes): 200 HP, armor that light blows can't interrupt, a 42-frame slam and a sweep for a flanking hero. Wait it out, punish the 48-frame recovery, and break its poise with the third hit.
- **The Skirmisher** (the loup-garou): fast, a 2.6-tile lunge with an 18-frame tell, then it springs back. It sidesteps the first swing it sees coming, so don't open with one: parry the lunge or punish it.
- **The Hexer** (the witch): keeps six tiles off and backs away from you. Its hex bolt paces itself to arrive on its planned frame, and a parry sends it back at the foes.
- **The threat manager** hands out attack tokens from three threat points (a Brute's costs two), no faster than one per 30 frames. No two strikes land within 18 frames (300 ms) of each other. Strikes are counted where they land, so a bolt's flight is included. The rest wait on a ring round you, to your sides and front.
- **Kits** (COMBAT.md §8): `--kits N` plays every hero at tiers 1, 4, 7 and 10; `--kit-parts T` shows what the blade, the shield and the path are each worth at tier T; `--kit-table` lists every blade and shield as the ring reads it.
- **The Vaults of Mammon fight the same way** (COMBAT.md §9): every foe there is a duelist on one of the three archetypes (the draugr a small brute, the ravens skirmishers, the bog slime a hexer that spits green), asleep at its post until he comes near, then paced by the threat manager (two threat points there, a token a second), finding its way round walls, going home when he is long gone. His blows and theirs land on their frames; his shield wears as it blocks and breaks for good; his blade dulls; he can die. Kills bring their coins, streaks and points, and now and then a health potion. Bombs and the archangels still work, as blows through the foes' poise (Michael's fire awes a foe into a stagger). `--crawl N` sends the bots through the vaults.
- **Tuning** (COMBAT.md §7): `AdventuresOfTheAncientBlades.exe --balance N` has three scripted players (novice, adept, expert) play every bout N times through the real controller path and prints win rate, time to kill against each bout's target, health lost, parries, blocks, mistakes and overlaps. The capture command `bot:K` lets one play in a capture. When a bout ends, a results card shows the same numbers, and a line goes into `combat_log.csv` in the save folder.
- **On screen**: the floor shows each attack's reach, filling through its startup and flashing in the commit frames. A foe glows through its wind-up, flashes on its strike and dims in its recovery (punish now). Each foe has health and poise bars, and token holders wear a red pip. **F8** shows the frame readout: your state and frame, the buffer, threat points in use, each foe's way of attacking (melee, body or distance) and its state, and the bout's numbers (damage, parries, blocks, evades, breaks, overlaps). **F6** skips to the next bout.
- **Bouts**: the Brute; the Pack (two Skirmishers); the Hexer's Guard; the Trio; the Gauntlet (five); then the third stage's foes: Steel (the tengu and the rasetsu), Fang and Fire (the dire wolf, the cobra and the jorogumo) and the Night Parade (all five).
  - Then two for each later stage: The Iron Club and The Fox's Wedding (stage 4), The Call in the Cold and Zemheri Nights (stage 5), The One Eye and The Old Tales (stage 6), Fire and Ice and Ragnarök (stage 7).
  - And last the princes, each alone as in his court: The Prince of Greed (Mammon, measured with tier-2 kit; COMBAT.md §13).
  - Lose and the bout begins again with you back on your feet. Win and the next one comes. **F7** skips to the next stage's bouts.
  - `--stage-three N` plays the third stage's bouts with every bot at kit tiers 1, 4 and 7 (COMBAT.md §10). `--stage S N` plays any later stage's at three tiers about its own (§11). `--bout K SKILL TIER SEED` plays one, and with `VH_TRACE=1` it prints every blow on the hero.

Code: `src/logic/combat/` (the rules: `frames`, `math`, `fsm`, `threat`, `archetype` and its breeds, `duelist` with its terrain and dens, `kit`, `prince` the fourth archetype), `src/game/brawl.rs` (the fight in the ring and the vaults: hits both ways, bolts, dens, wear), `src/game/sparring.rs` (the bouts), `src/render/view/duel.rs` (poses, telegraphs, pips, bolts), `src/render/hud/ring.rs` (bars, banner, readout, results card), `src/game/bot.rs` (the scripted players and the balance harness); tests in `src/game/ring_tests.rs`.

## The loadout

A fifth tab at the old gatekeeper's, LOADOUT, beside the four trees (`src/game/shop.rs`):

- **Archangel's protection:** swear to one of the four archangels, free, and change at any time. His power is yours on R or LT whenever it has come back: Michael in 10 seconds, Gabriel 20, Raphael 30, Uriel 45. The HUD's corner shows his emblem filling as it returns, and a chime says when it has. A blessing taken at a shrine is used first while you carry one.
- **Outfits:** four for each hero, recolouring his clothes (Ragnar: Berserker, Raven, Jarl, Frost; Mehmed: Janissary, Sultan's Guard, Midnight, Desert; Miyamoto: Crimson, Shadow, Jade, Ivory). Free, and seen at once on the hero in the crypt.
- **Weapon decay:** every swing that lands wears the wielded blade's edge (each blade keeps its own), and its iron reddens with rust. A dull blade bites the boss less (down to four tenths, rusted through); under a fifth it is rusted and glances off one ordinary foe in three, which reels but stands. The HUD shows the edge under the weapon; SHARPEN puts it back for gold (as much as mending a shield).
- **Shields break for good:** a shield worn to nothing is struck off (saved at once), and is no longer carried into an adventure or offered on the shields' tab until REFORGE forges it anew, for twice the price of mending it from nothing. Hold **LB** (or **Shift**) to raise it: it comes off his back and up before him, takes the whole of every blow (not only its share), but he walks at a little over half pace and cannot strike.
- **Skill ribbons:** each skill of his path he has learned is a band round his shield arm, in that skill's colour, the first tied with hanging ends.

Saves are now `v2` (the patron, the outfit, the broken shields and every blade's edge); a `v1` save still loads.

- **Sword:** each swing has a wind-up, a snapping strike with the hips turning into it and a small lunge, then a follow-through. Swings alternate forehand and backhand, with a sweeping trail. A swing fells every foe it catches, not just one. That means everything within its reach and everything the trail sweeps through, about 66 degrees either side of the aim, as wide as the slash is drawn. Foes count as bodies 0.4 tiles across, not points (`in_blade_arc`, `FOE_RADIUS` in `src/logic/systems.rs`).
- **Impact feedback:** micro dust bursts on kills, hits, shots striking walls, landings, footsteps and blasts. Screen shake scales with the impact (a tap for a wall hit, a jolt for a bomb at your feet), and kills get a brief freeze-frame.
- **Loadout panel:** the bottom-middle panel shows the held weapon with ammo pips, shield charges, and each running potion with a bar that drains as it wears off.
- **UI visibility:** larger text, drop shadows on all text, darker bordered panels, a trailing damage chunk on the health bar, and a red screen-edge flash when hurt.
- **Dynamic audio:** every effect varies a little in pitch and volume. Kill streaks climb in pitch, forehand and backhand swishes differ, and footsteps alternate (they squelch in slime). The music layers in extra hats and ghost kicks as enemies close in, and it muffles when health runs low.
- **Juiced rewards:** collected nuggets fly into the HUD counter, which punches in. The score rolls up, floating text pops in, and every five nuggets gets a banner and a chime.
- **Soundtrack:** a Norse war song in D minor at 100 BPM. A war horn opens it over a hurdy-gurdy drone on D and A. Under that sit galloping war drums, stomps and claps, a plucked lyre, a bone-flute melody, a chanting choir in the second half, and "HEY!" shouts at the turnarounds. The first pass builds up layer by layer and every fourth bar ends in a tom roll. `AdventuresOfTheAncientBlades --write-music out.wav [seconds] [intensity]` renders it to a file.
- **Turning on the spot:** standing still, tapping a direction turns Popolon to face it without stepping, and holding it walks. A blocked direction (wall, pit) just turns him, so you can aim a swing, a shot or a jump anywhere.
- **Weight:** Popolon no longer snaps to full speed. Holding a direction accelerates him to the same top speed as before in 0.2 s. Letting go coasts him to rest on the next tile center under friction. Reversing brakes before he turns, and corners bleed a little speed. Hitboxes, `occupied` tiles and collisions are unchanged (`src/logic/hero.rs`, covered by tests).
- **Boss: the Cyclops.** Collecting all 25 nuggets plays the fanfare, then the game fades into the Cyclops' Meadow. It is the same dungeon's outer ring, but the labyrinth in the middle is torn out and replaced with a sunny grassland: grass tufts, flowers, round bushes (some with berries), stone pillars, low brick walls, and a stream crossed by three wooden bridges. The Cyclops is a giant floating eye with horns, bat wings and tentacles. It drops in after the countdown, drifts around keeping its distance, squints and glows to telegraph, then attacks with bolt fans, bolt rings, tracking bolt streams and rolling boulders. Pillars and walls block its shots, and jumping clears them. At two thirds and one third health it grows angrier and faster, a green cross appears, the music steps up, and it starts diving at you. A dive that misses leaves it dazed in the grass for 2 seconds, taking double damage. The first Cyclops has 32 health, a third more than before, and each later one 12 more. Damage per hit: axe 2, shots 1 (fireball 2), bombs 6. Felling it gives 5000 points and leads on to the next dungeon. Losing a life sends it back into the sky, but it keeps its wounds. In the arena the chase camera turns to keep the Cyclops in frame unless you steer the camera yourself. Code: `src/logic/boss.rs` (rules), `src/render/view/meadow.rs` (meadow and boss rendering), `boss_arena` in `src/logic/levels.rs`.
- **The blacksmith** (Hrolf's forge, four weapon lines of three levels, four shields, eleven potions) has been replaced by the old gatekeeper and the heroes' trees, described above.
- **First-run tour:** the first new game on a machine opens with a cinematic tour before the countdown. The game holds still, letterbox bars slide in, and the camera swoops from Ragnar to a gold nugget, a green cross, a potion, both shrines and a pit, then to each foe (shown in their hollow). A see-through card names and explains each one, with a lock-on frame around it. Enter, click or A moves on, and each stop also moves on by itself after 3.3 s; Esc skips. It is remembered as `vh.tour_done=1` in `%APPDATA%\VoidHarvest\settings.txt`; delete that line to see it again. Code: `src/game/tour.rs`.
- **BRUTAL streaks:** every third kill within a streak (kills at most 2.5 s apart; it was 1.6 s) sets off BRUTAL. A heavy screen shake, a freeze-frame, a hot flash, a big BRUTAL! banner and an impact sound. Then every point (kills, nuggets, crosses, boss hits) counts double for 10 seconds, shown by a x2 POINTS badge under the score.
- **Sculpted items and objects:** every prop is re-sculpted in voxels at three to four times the old resolution, at the same world size (`src/render/props.rs`). That covers lumpy gold nuggets with glints; green crosses with a bevel and a white plus; a round riveted iron bomb with a rope fuse that sputters sparks; fletched arrows with steel broadheads; banded boomerangs; ragged fireballs; crescent blades; round glass potion flasks half full of their brew, with a cork and twine; faceted shrine gems on carved stone pedestals with glowing rune rings; iron-caged lanterns; and Norse pines for the forest. The HUD's bombs are pixel icons too.
- **Forest terrain:** dungeon paths are even green grass tiles with only the odd tuft. Their top faces are drawn with parallax occlusion mapping (`grass_shade` in `src/render/shaders.wgsl`, shading mode `SHADE_GRASS`). The fragment shader marches the view ray down into a procedural field of thin, pointed grass blades, about 26 per tile, reaching 7 cm deep. It shades by where the ray lands (dark roots, bright yellow-green tips, each blade its own shade), so the flat tile reads as a lawn with depth. It fades to plain green with distance to avoid shimmer, and it costs nothing on the CPU. Raised ground shows earthen cliffs, and ramps are mossy stone steps. Walls are low mossy mounds edged along every road by a dry-stone fence (two staggered courses and moss-topped cap stones), with ferns and bushes behind it. The woods on top are a mixed forest of pines, oaks and white birches, denser away from the roads. Bombs still blast through, taking the fence, bushes and trees with them. Code: `src/render/view/forest.rs`, trees in `src/render/props.rs`.
- **F1 cheat:** jumps straight to the first Cyclops fight from anywhere, for testing. The FPS counter moved to F3.
- **Recorded soundtrack:** dungeon I plays "The New Adventure" (`assets/music/level1.ogg`), looping, from the countdown on. The title, the shop and the other stages keep the synth tune. The 42 MB studio WAV (48 kHz stereo, 3:39) was encoded to Ogg Vorbis at quality 0.5 (about 148 kbps, 3.9 MB) with Python `soundfile`, writing in 4096-frame blocks because a single large write overflows libsndfile's stack. The file is built into the binary and decoded a packet at a time in the audio callback by `lewton` (pure Rust, so the web build plays it too), resampled to the device rate. It plays in stereo alongside the mono synth effects, ducks under pauses like the synth tune did, and muffles as Ragnar is hurt. It does not speed up every five nuggets; only the synth tune does. Code: `src/audio/track.rs`. To add a track, encode it the same way, add a `Soundtrack` variant and pick it in `Game::enter`.
- **Golden keys, a gate, and estates four times the size:** each dungeon is now an estate of four classic dungeons joined together (53 x 45 tiles, `compose_estate` in `src/logic/levels.rs`). The classic dungeon is mirrored right and down again so floor levels meet across the seams, and passages are opened through the shared walls. One enemy hollow is kept; the others become walled courtyards. Each quarter keeps an archangel's shrine (once a weapon shrine) and an item shrine, and there are 10 potions and 18 pits. Instead of 25 gold nuggets, **8 golden keys** are hidden, two per quarter, far from the start and favoring dead ends (`place_keys`). They spin with a golden halo and a faint beam of light so they can be found across the estate, are worth 400 points and 30 coins each, and every other key quickens the music. The HUD shows a row of eight keys. The last key doesn't end the level: it unlocks **the gate** in the middle of the north wall, a gatehouse with two battlemented towers, a pointed arch, oak doors banded with iron, smoking braziers and eight lock lamps (one lit per key), sending up a beacon once unlocked. Walk up to it and the doors swing open on a golden glow; step through to face the Cyclops. Coming to it early shows how many keys are missing. **F2** (a cheat, like F1) grants every key and puts Ragnar at the gate. Code: `src/game.rs` (`update_gate`), `src/render/view/gate.rs`.
- **Health, draugr and music:** an estate holds just 6 health potions and no green crosses; the boss arenas have no crosses either. Draugr rise out of the churchyard: they start, respawn and arrive as reinforcements beside its graves, climbing up in pieces and pulling themselves together ("THE DEAD RISE"). Where there is no churchyard they still come from the hollow. The title screen and the blacksmith play "TheMenu1" (`assets/music/menu.ogg`), and the Cyclops fight plays "BossFight" (`assets/music/boss.ogg`). Both are encoded like the level 1 track (Ogg Vorbis q0.5, 2.7 MB and 2.2 MB), with their gain set to match its loudness.
- **Free movement (F4 toggles it; on by default):** Ragnar can run in any direction instead of tile to tile. He moves in 8 directions: keys add up (W+D runs diagonally, opposite keys cancel) and the stick snaps to the nearest of eight, relative to the camera, with the same acceleration, friction and top speed as before. He slides along hedges, walls, pits and ledges too high to climb, walks smoothly up ramps and steps down drops. The rest of the game still sees the tile he stands on for pickups, puddles and the gate. Since 2026-09-29 the left stick points any way at all, not one of eight, and whatever he does goes the way he faces, at any angle (`Hero::aim`). That covers sword arcs, shrine taps, thrown and fired weapons (spread shots go out square to it), waves, holy-fire trails and arrow volleys. Leaps follow his heading and come down wherever they land: two tiles on if the spot is floor no more than a level up with no rock in between, else one, else a hop in place. Blinks and lunges stop short of whatever he could not walk into. Bombs lie at his feet but still blast from their tile. It had also never lasted past the title: every level load made a new hero in grid movement. The choice now carries through, which is why free movement finally feels free. The chase camera turns after him only while he runs straight ahead, so running diagonally, sideways or back keeps each of the eight directions steady; turn the view with the mouse or the right stick. The choice is saved as `vh.free_move`. Code: `Hero::drive_free` in `src/logic/hero.rs`. The boss arenas no longer have potion bottles.
- **The Krampus fountain and its four channels:** the middle of Dungeon I's estate, where the two long walls that quarter it cross, is now a fountain (`src/render/view/fountain.rs`). An octagonal stone basin with panelled sides and a lantern on four corners holds a pedestal and a shallow bowl that brims over all round in a veil of falling water. On a rock in the bowl stands a bronze Krampus, sculpted in voxels with materials: gilt cloven hooves, a shaggy coat gone green with verdigris, a wicker basket of switches on his back, a bundle of gilt birch rods raised in one fist and an iron chain hanging from the other, a chain belt with bells, gilt ram's horns, ember eyes that glow, fangs, and a long red tongue with water running off its tip. Four jets arc in from the basin's sides and land in the bowl, rings spread where the water falls, droplets jump and spray drifts off, and a lamp under the water lights him from below. The path tiles at its corners are paved in rings. From its basin **four channels** run straight out along the middle row and column, through the wall and under a balustraded bridge wherever a path crosses (16 bridges; slimes still cannot cross, so each quarter keeps its own slimes). East, south and west pour off the island into the clouds, with spray and mist boiling up below; north ends in a still pool short of the gate. Each channel flows its own way (the water shader takes the current per tile), steps down over a weir where the ground drops, and carries lilies, reeds and foam. The plan is `fountain_channels` in `src/logic/garden.rs`; Ragnar now starts on a corner of the fountain's plaza, and the first-run tour stops at the fountain with a picture of Krampus.
- **A smoke wall round the island:** the smoke round the level now rises to about five times Ragnar's height (5.8 units, heaving between 4.9 and 6.7). Five ranks of tall curtains stand round each side (`SMOKE_RANKS` in `src/render/view.rs`, `smoke_wall` in `src/render/shaders.wgsl`), each a sheet of slowly rising, billowing smoke: solid low down where it meets the cloud sea, breaking into billows toward a moonlit crest where the stars show through. The billows are lit by the moon from their own slope, in smooth quintic noise so the lighting shows no seams. A rank thins away as the camera comes up to it, so the view from near an edge stays clear, and the ranks between a far camera and the island (the map view) are left out.
- **Better shadows, lighting and effects:** the moon's shadow map is now two cascades in one array: a fine one (20 x 20 units, about 200 texels a unit) over the ground ahead of Ragnar, stepped a whole texel at a time so its edges never crawl, and the whole-level one. Both are filtered as soft shadows that harden where an object meets the ground (a blocker search sets how far a 16-tap Vogel disc spreads), with a much smaller bias, so shadows no longer float off their casters. Moonlight streams past trees and smoke as light shafts when the moon is on screen (`fs_rays`, added into the glow). Lanterns and candles near Ragnar wear soft halos in the damp air, five candles (was three) cast light, fireflies flash in their own rhythms instead of glowing steadily, three will-o'-the-wisps wander over the churchyard trailing sparks and throwing a pale green light, braziers and fire bowls throw up embers, and characters and statues catch a cool rim of moonlight. Point lights out of reach are skipped in every shader, which paid for all of this: a 1080p frame costs about what it did before.
- **More mist and smoke:** ground mist is thicker (three sheets everywhere, four over water and graves), and smoke curls up from the gate's braziers and from every candle in the garden.
- **The Cyclops' Meadow at dusk:** the boss arena gets the same treatment. The sky is a new dusk skybox: flame at the horizon through rose and violet to deep blue, a low sun with a wide glow, streaky clouds lit gold on the sun's side and the first stars overhead (`dusk_sky`). The arena floats on a mauve cloud sea, its lawn has the parallax grass, and its stream runs in the stone channel with the reflective water, lilies and reeds under stone bridges. Fire bowls smoke on the stone pillars, and mist lies over it all.
- **Dungeon I, an English landscape garden:** the first dungeon is dressed as a night-time landscape garden, planned from its fixed maze by `src/logic/garden.rs`. Its water now runs from the Krampus fountain in four channels (see above) in stone-edged beds with lily pads and reeds; wherever a channel crosses a path, the crossing becomes a balustraded stone bridge (stepped where the path climbs a ramp). The boss meadow's stream still rises from a rocky grotto. The garden also has a churchyard behind wrought-iron railings (leaning headstones, crosses, obelisks, a dead tree, a tomb and grave lanterns), walled flower gardens and parterres inside clipped box hedges (roses, lavender and white, yellow and blue blooms with topiary and urns), two round classical temples with green copper domes, and six wayside shrines and urns. Candles in the shrines, temples and graves light their surroundings. The water, the fountain, the churchyard and the temples cannot be bombed. **Slimes cannot cross bridges:** the channels split the garden, and the slimes stay in their quarter. The water is drawn each frame with its own shader (`SHADE_WATER`): rippled, mirroring the starry sky and the moon, glinting with lantern light, with falling cascades and foam. Code: `src/render/view/garden.rs`.
- **Night mist:** thin drifting sheets of ground mist lie over every forest level, thicker over water and graves. They thin out right in front of the camera and are warmed by nearby lights.
- **Slime trails:** slimes leave glossy splats of goo with droplets flung around them, smeared into one continuous track from tile to tile. Bubbles swell and pop in them, and they shrink away as they dry.
- **Night sky and cloud sea:** the forest levels sit under a black sky with three layers of twinkling stars, a faint milky band and a full moon (a full-screen sky pass, `fs_sky`). The dungeon floats on a sea of drifting dark clouds: stacked procedural mist layers (`SHADE_CLOUD`) that bank up against the level's sides and thin out away from it.
- **Foes come by progress, not by place** (`logic::realms::Dealer`, `Game::dungeon_cast`): every level sends the foes met so far plus one new stage, counted by how far he has come, whichever level it is. The Garden has the first stage; the first realm taken (the Vaults of Mammon or any other) brings in the second; every realm after it one stage more; the last realm all seven, led by the sixth and seventh. A realm's packs are dealt the same way every time: by turns one foe that fights with its body, one in melee and one from afar (so every pack mixes the three); of each, first every foe of the new stage, then every one met before (latest first), then new and old by turns. A realm with room holds the whole roster; a small one leaves out the oldest. Each realm keeps its own creatures (the Peerless, Hel's servants, the gaki, the elf-maids). The side dungeons on the map send their own stage plus one foe of each stage before it.
- **Only the slime slows him:** the bog slime's trail is the one foe-made thing that slows him (see the frostbite, roots, pounce, grab, roar and smoke entries in COMBAT.md §11 for the rest); the realms' own ground (mud, thorns, Bloat) and his raised shield still do.
- **Sword in the right hand, shield on the left arm:** the heroes' rigs are mirrored so the weapon sits in the right fist, and the shield of his tree is strapped to the left forearm, swinging with it (raised, it comes up before him). Every shield adds health while it is on his arm: 5 at tier 1 up to 60 at tier 10; a broken one takes its share with it.
- **Lighting and post-processing (stage 1):** each frame draws a 4096² shadow map from the moon (or the meadow's sun) over the whole level, sampled with a 16-tap filter for soft edges. The scene pass writes color plus world normals and view depth. From that buffer come contact shading (SSAO, at half resolution with a depth-aware blur), a five-level bloom chain for glow, and a composite with background depth of field (in focus on Ragnar), gentle grading and a vignette. The HUD is drawn afterwards, sharp. Code: `src/render/gpu.rs`, `src/render/post.wgsl`.
- **Detailed Ragnar:** the hero is sculpted at twice the old resolution (30x46x18 then; since doubled again, see "Finer characters"). It has a riveted spangenhelm with bronze strips and ivory horns, a braided fur beard with gold rings, a fur mantle, a woven tunic with embroidered hem, a stitched belt with gold buckle and pouch, laced bracers, cross-gartered trousers, fur-cuffed boots, and all axes and shields rebuilt. Voxels carry materials in the top byte of their color (metal, fur, cloth, leather, skin, ivory, wood, gold). The shader gives each face its own procedural detail and shine (`voxel_surface`): hammered dents, woven threads, fur strands, wood grain and polished highlights, faded out at a distance. The HUD portrait kept the old pixel model at first; it now shows the detailed hero.

## Layout

```
src/logic/     rules: grid, level generation, hero, enemies, items, projectiles, systems
src/game.rs    screens, the round, and the rules that tie entities together
src/render/    view.rs (scene -> instances + lights), gpu.rs (wgpu), shaders.wgsl, post.wgsl, hud.rs, overlay.rs, voxels.rs
src/audio/     software synth, lo-fi music sequencer, sound effects
src/input.rs   keyboard, mouse, touch and gamepad mapped to actions
src/app.rs     winit window, event loop, fixed 120 Hz step
src/capture.rs headless screenshots: --capture out.png --time 6 --script "0.1:confirm,0.3:pause,0.6:confirm,3:+up,4:bomb" [--iso] [--closeup DEG] [--view x:y:z:angle:dist[:rise]] [--bench N]; beat:N:T jumps into Scene I
steam/         SteamPipe build scripts and the release checklist
```

The dungeon generator uses the same seeded RNG and hash as the TypeScript version, and a test checks that the generated layout matches the web build tile for tile. Lighting follows Three.js (Lambert, hemisphere, physically based point-light falloff, ACES filmic, fog after sRGB encode). Sampled pixels match the Three.js build to within one or two levels.
